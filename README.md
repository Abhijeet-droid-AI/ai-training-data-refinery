# AI Training Data Refinery

A production-style data engineering pipeline that transforms raw web-scale text into high-quality datasets suitable for training Large Language Models.

## Goals

- Build scalable ingestion pipelines
- Clean and normalize text
- Remove duplicates
- Score document quality
- Detect anomalies
- Train small language models
- Compare dataset quality through experiments

## Tech Stack

- Python
- PyArrow
- DuckDB
- Polars
- Docker
- Kubernetes
- Hugging Face
- Streamlit
